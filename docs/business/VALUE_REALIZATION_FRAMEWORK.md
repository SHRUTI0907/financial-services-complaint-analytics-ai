# Value Realization Framework

## Inputs
- Observed complaint volume from CFPB data.
- External wage benchmark from BLS OEWS.
- User assumptions for handling time, AI-addressable share, AI time reduction, adoption, implementation cost, operating cost, success probability, and discount rate.

## Outputs
- Observed workload hours.
- Expected hours released.
- Estimated annual capacity value.
- Annual net value.
- 3-year net value.
- ROI.
- NPV.
- Payback period.

## Controls
- All assumptions are editable.
- Outputs are labeled as estimates.
- The app must not describe scenario outputs as actual savings.
- Sensitivity analysis identifies which assumptions drive the model most.
