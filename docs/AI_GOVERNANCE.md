# AI Governance Methodology

## Official Concepts Used
The project uses NIST AI RMF concepts as governance dimensions:
- validity and reliability;
- safety;
- security and resilience;
- accountability and transparency;
- explainability and interpretability;
- privacy;
- fairness with harmful bias managed;
- human oversight.

The NIST AI RMF Core functions of govern, map, measure, and manage inform the control workflow.

## Project-Specific Implementation
The app translates those concepts into practical controls for:
- complaint routing and triage;
- complaint summarization;
- agent-assist retrieval;
- root-cause detection;
- emerging-risk monitoring;
- executive RAG assistant.

## Control Examples
- Complaint summarization requires source-grounded generation, citations, human review, logging, and quality thresholds.
- Complaint routing requires classifier evaluation, low-confidence escalation, drift monitoring, and segmented performance checks.
- Executive RAG requires deterministic metric retrieval, citation requirements, abstention behavior, and unsupported-claim checks.

## Limitations
This project does not claim legal advice, regulatory approval, compliance certification, or production readiness. It is an analytical governance design pattern for portfolio and implementation planning.
